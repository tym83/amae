## Программы и души

```
written by "ana"     who wrote the program: its consent to be compiled
```

Каждая программа один раз, вне всякой души, говорит, кто её написал;
программу без этой строки не компилируют ([Компиляция как
свидание](#компиляция-как-свидание)).

Программа состоит из объявлений. Каждое начинается строкой-заголовком и
заканчивается строкой, на которой стоит одно только `end`.

```
soul NAME            a soul that is alive when the program starts
kind NAME            a kind of soul, from which souls are brought to life
ritual NAME a, b     a ritual (a subroutine) with parameters a and b
```

`soul` объявляет душу, которая жива с самого начала программы; `kind` —
род душ, из которого души потом призывают к жизни; `ritual` — ритуал, то есть
подпрограмму, с параметрами.

Каждая строка программы принадлежит какому-нибудь из этих объявлений, вне их
ничего стоять не может. Имена душ, родов и ритуалов не должны повторяться
среди себе подобных. В программе должна быть хотя бы одна `soul`.

У души свой код, своя память, свои заметки и свой взгляд на каждую душу, с
которой она встречалась. Общих переменных у душ не бывает. Узнать что-то от
другой души можно лишь одним способом: услышать это от неё.

## Лексические правила

- В строке одна инструкция. Строка делится на числа, строки, имена и
  операторы; пробелы между ними ничего не значат, отступы тоже.
- `#` вне строки открывает комментарий, который тянется до конца строки.
- Число записывается подряд идущими десятичными цифрами; если за ними стоят
  точка и ещё цифры, `3.25`, это десятичная дробь. Минус — это унарный
  оператор.
- Строка пишется в двойных кавычках. Внутри неё `\n` означает перевод строки,
  `\"` — кавычку, а `\\` — обратную косую черту; читаются они один раз,
  слева направо, а обратная косая черта перед любым другим символом так и
  остаётся обратной косой чертой.
- Число, записанное в программе, должно умещаться в 64 бита.
- Имя начинается с буквы или `_`, а дальше в нём идут буквы, цифры и `_`.
  Заглавные и строчные буквы в именах различаются.
- Операторы: `+ - * / % == != < <= > >= = ( ) , [ ] { } :`.

### Зарезервированные слова

Эти слова нельзя брать в имена переменных, параметров, душ, родов, ритуалов
и мгновений:

```
afraid and anyone as back bond bring commitment confide cool end else
first for forgive from give goodbye hear heart if in intimacy into kind
knowingly leave length let mark me meet named not note number of or part passion
perform place promise recall return ritual runs say scar scars silence
soul tell time to trust wait warm while with word words world wound cry
ask telling listen read write append file seconds endure when hurts learn
keys json meaning whole fate now put remove lines send receive letters thank
hope hoping resentment toward apologize tenderly take distance jealous ashamed
before longing admit consent withdraw together apart guard crossings
is anxious avoidant secure eros ludus storge pragma mania agape knowingly deterministic chemistry love phase core lineage hash source written by
```

Среди них есть и самые обиходные слова вроде `word`, `words`, `first`,
`back` и `kind`; если программе нужна переменная с таким смыслом, придётся
назвать её как-нибудь иначе.

## Значения

| Значение | Запись | Пояснения |
|---|---|---|
| целое число | `42`, `-7` | 64 бита, от −2⁶³ до 2⁶³ − 1; результат, который в эти пределы не умещается, — ошибка |
| дробь | `3.25`, `1 / 4.0` | 64-битное число с плавающей точкой |
| строка | `"hello"` | UTF-8; длины и части считаются в символах |
| список | `[1, "two", [3]]` | элементы считаются с 1 |
| словарь | `{"name": "ana", "age": 30}` | ключи — слова, и хранятся они в том порядке, в каком их впервые записали |

Логического типа нет: сравнение даёт `1` или `0`, а условие ложно, когда оно
равно `0`, `0.0`, пустой строке, пустому списку или пустому словарю. Ключ
словаря, как и ключ [заметки](#заметки), превращается в слово: `m[1]` и
`m["1"]` — одно и то же.

Что душа хранит, то принадлежит ей одной. Когда значение кладут в переменную
или заметку, говорят другой душе, передают ритуалу или сохраняют шрамом, оно
копируется целиком, до самого дна, так что изменить список можно только через
ту переменную, в которой он лежит.

## Выражения

От самых слабо связывающих операторов к самым сильным:

| Уровень | Операторы | Пояснения |
|---|---|---|
| 1 | `a or b` | `1`, если истинно хотя бы одно, иначе `0`; на `b` смотрят, только если `a` ложно |
| 2 | `a and b` | `1`, если истинны оба, иначе `0`; на `b` смотрят, только если `a` истинно |
| 3 | `not a` | `1`, если `a` ложно, иначе `0` |
| 4 | `== != < <= > >=` | на одном уровне одно сравнение; `a < b < c` — ошибка |
| 5 | `+ -` | слева направо |
| 6 | `* / %` | слева направо |
| 7 | `-a` | только для чисел |
| 8 | всё описанное ниже, имя, литерал, `( … )` | |

`+` склеивает два значения в строку, если хотя бы одно из них строка, сливает
два списка в один, а числа складывает: `"pod " + 3` даёт `"pod 3"`,
`[1] + [2]` даёт `[1, 2]`. Целое число вместе с дробью дают дробь; `/` между
двумя целыми по-прежнему округляет вниз, а `/` с дробью делит точно. `==` и
`!=` сравнивают любые два значения, и число никогда не равно строке. `< <= > >=` требуют двух значений
одного вида; строки сравниваются по кодам символов. `- * / %` работают только
с числами; `/` и `%` округляют в сторону минус бесконечности, а делить на ноль
нельзя — это ошибка.

Одинокое имя читает переменную из памяти души, а она могла уже
[выцвести](#память). Прочесть имя, которому никогда ничего не присваивали, —
ошибка.

### О самой душе и о запуске

| Выражение | Значение |
|---|---|
| `me` | собственное имя души |
| `runs` | сколько раз эта программа запускалась прежде ([Запуски](#запуски)) |
| `note k` | заметка, записанная под ключом `k` ([Заметки](#заметки)); если её нет — ошибка |

### О другой душе

`S` здесь — либо имя души, написанное прямо в коде, либо `soul named <expr>`,
то есть имя, вычисленное во время работы программы.

| Выражение | Значение |
|---|---|
| `trust S` | насколько эта душа доверяет `S`; доверие отсчитывают `warm to` и `cool to` |
| `intimacy S` | насколько близкой эта душа чувствует `S` |
| `passion S` | насколько эту душу тянет к `S` |
| `commitment S` | сколько обещаний эта душа дала `S` |
| `bond with S` | название связи по треугольнику Стернберга ([Связи](#связи)) |
| `afraid of S` | `1`, пока эта душа боится `S`, иначе `0` |
| `scars of S` | сколько шрамов эта душа носит от `S` |
| `scar n of S` | n-й шрам, считая с 1; если такого шрама нет — ошибка |
| `distance from S` | насколько они отдалились друг от друга ([Расстояние](#расстояние-и-внимание)) |
| `longing for S` | `1`, пока они далеко друг от друга (расстояние 2 и больше), а страсть ещё не прошла |
| `resentment toward S` | `1`, пока эта душа держит обиду на рану, которую нанесла ей `S` |
| `ashamed before S` | `1` с тех пор, как эта душа ранила `S`, отдавшую ей сердце, и до тех пор, пока не попросит прощения |
| `jealous of S` | `1` с тех пор, как `S`, которой принадлежит сердце этой души, доверила тайну кому-то другому |
| `hoping for S` | `1`, пока эта душа надеется на `S` |
| `letters from S` | сколько писем от `S` пришло и ещё не прочитано |
| `consent from S` | `1`, пока `S` даёт этой душе своё согласие |
| `crossings with S` | сколько раз граница между ними была пересечена |
| `chemistry with S` | то, что принесла их первая встреча и чего никто не мог рассчитать: −1, 0 или 1 ([Химия](#химия)) |
| `love for S` | любовь, которую эта душа построила с `S` ([Любовь строится](#любовь-строится)) |
| `phase with S` | `"strangers"`, `"acquaintance"`, `"lust"`, `"attraction"`, `"attachment"` или `"love"` ([Любовь строится](#любовь-строится)) |
| `note k of S` | заметка `k` другой души, если та впускает эту ([Границы](#границы)) |

Все они говорят о том, какой эта душа видит `S`; отношения не симметричны.
Душа, ни разу не встречавшая `S`, не видит ничего: нули, `nothing yet`, ни
одного шрама.

### Текст

| Выражение | Значение |
|---|---|
| `length of s` | сколько символов в `s` или сколько элементов в списке или словаре |
| `part a b of s` | символы `s` с `a`-го по `b`-й, считая с 1, оба включительно |
| `words of s` | сколько слов в `s`, если делить по пробелам |
| `word n of s` | n-е слово `s` или `""`, если такого нет |
| `place of x in s` | на каком месте среди слов `s` стоит слово `x`, в списке — элемент, равный `x`, в словаре — ключ `x`; `0`, если такого нет |
| `number of s` | число, записанное в `s`, целое или дробное; если `s` не число — ошибка |
| `lines of s` | строки текста `s` списком, без их переводов строки |

### Списки, словари и JSON

| Выражение | Значение |
|---|---|
| `[a, b, …]` | список |
| `{k: v, …}` | словарь |
| `x[i]` | i-й элемент списка, значение под ключом `i` в словаре или i-й символ строки; если такого нет — ошибка |
| `keys of m` | ключи словаря списком |
| `json of v` | `v`, записанное в JSON |
| `meaning of s` | JSON из `s`, прочитанный обратно: объекты становятся словарями, массивы — списками; `true` — это `1`, `false` — `0`, а `null` — пустая строка |
| `whole of x` | целая часть числа, округлённая вниз |

### Окружение и время

| Выражение | Значение |
|---|---|
| `world e` | переменная окружения по имени `e` или `""` |
| `now` | который сейчас час, в секундах с 1970 года, дробью |
| `fate n` | целое число от 0 до `n − 1`, какое выпадет по воле случая; `TAINTED_FATE` закрепляет случай на весь запуск |
| `lineage` | компиляторы, которые сделали эту программу, по строке на каждый ([Родословная](#родословная)) |
| `source` | исходный текст, из которого скомпилирована эта программа |
| `hash of x` | SHA-256 от `x` как текста, в шестнадцатеричной записи |

Операнд после `of` и `in`, а также индексы у `word`, `part` и `scar` —
унарные: литерал, имя, ещё одно такое же выражение или что-то в скобках.
`word i + 1 of s` — ошибка, писать нужно `word (i + 1) of s`. То же касается
`note`: `note ("likes " + name)`.

## Инструкции

| Инструкция | Что делает | Ждёт ли? |
|---|---|---|
| `let x = e` или `x = e` | кладёт `e` в переменную `x` | нет |
| `say e` | печатает `e` и перевод строки на стандартный вывод | нет |
| `cry e` | печатает `e` и перевод строки в стандартный поток ошибок | нет |
| `meet S` | [встречается](#встреча) с `S` | пока `S` не придёт на встречу |
| `meet anyone as x` | встречается с тем, кто ищет эту душу; его имя попадает в `x` | пока кто-нибудь не придёт |
| `tell S e` | [говорит](#говорить-и-слышать) `S` значение `e` | пока `S` не услышит |
| `tell S e tenderly` | то же самое, но бережно: слово не давит на `S` и делает её ближе | пока `S` не услышит |
| `knowingly confide S e` | доверяет `S` тайну; только той душе, которой эта отдала сердце | пока `S` не услышит |
| `hear S into x` | слушает `S` и кладёт услышанное в `x` | пока `S` не скажет |
| `hear anyone into x` | слушает того, кто первым заговорит с этой душой | пока кто-нибудь не заговорит |
| `hear anyone into x from y` | то же самое, а имя говорящего попадает в `y` | пока кто-нибудь не заговорит |
| `hear world into x` | читает строку из [мира](#мир) в `x` | пока мир медлит |
| `warm to S` | доверие к `S` вырастает на единицу | нет |
| `cool to S` | доверие к `S` падает на единицу, но не ниже нуля | нет |
| `promise S` | верность `S` вырастает на единицу | нет |
| `give heart to S` | отдаёт `S` сердце этой души и забирает его у той, кому оно принадлежало прежде ([Одно сердце](#одно-сердце)) | нет |
| `knowingly wound S` | ранит `S` ([Раны](#раны)) | нет |
| `forgive S` | после раны снова открывает эту душу для `S` | нет |
| `apologize to S for scar n` | просит прощения за ту рану, что значится у `S` шрамом номер `n` ([Извинения](#извинения)) | нет |
| `admit resentment toward S` | называет обиду этой души, и душа от неё избавляется | нет |
| `thank S` | благодарность: верность `S` растёт, а `S` чувствует, что они стали ближе | нет |
| `hope for S` | эта душа надеется: её страсть к `S` больше не остывает | нет |
| `take back heart from S` | забирает назад сердце, отданное `S` | нет |
| `consent to S` | соглашается делать что-то вместе с `S` | нет |
| `withdraw consent from S` | отзывает согласие, даже посреди общего дела | нет |
| `together with S` … `apart` … `end` | делает что-то вместе с `S` ([Согласие](#согласие)) | пока обе не согласятся и не придут |
| `guard k` | прячет заметку `k` за границу этой души | нет |
| `send S e` | посылает `S` письмо, которое придёт в свой срок ([Письма](#письма-и-горе)) | нет |
| `receive from S into x` | читает письмо от `S` | пока какое-нибудь не придёт |
| `receive anyone into x from y` | читает первое пришедшее письмо и узнаёт, кто его написал | пока какое-нибудь не придёт |
| `knowingly leave S` | уходит от `S` навсегда ([Уход](#уход)) | нет |
| `note k = e` | записывает `e` под ключом `k` ([Заметки](#заметки)) | нет |
| `recall a b …` | перечитывает переменные, чтобы они не выцветали | нет |
| `bring K named e` | призывает к жизни новую душу рода `K` по имени `e` | нет |
| `perform R with a, b into x` | совершает ритуал `R` ([Ритуалы](#ритуалы)) | пока он длится |
| `give back e` | завершает текущий ритуал и возвращает `e` | нет |
| `wait` | один шаг ничего не делает | один шаг |
| `wait for silence` | ждёт, пока никто другой не сможет ничего сделать ([Тишина](#тишина)) | да |
| `x[i] = e` | меняет элемент списка или словаря на любой глубине: `grid[2][1] = 9` | нет |
| `put e into x` | добавляет `e` в конец списка, лежащего в `x` (или в `x[i]…`) | нет |
| `remove k from x` | вынимает из списка элемент `k`, а из словаря — ключ `k` | нет |
| `ask world c into x` | запускает команду `c` и ждёт того, что она напечатает ([Мир](#мир)) | пока она не кончится |
| `ask world c telling t into x` | то же самое, а `t` команда получает на вход | пока она не кончится |
| `listen to world c` | запускает команду `c`; каждая напечатанная ею строка приходит к `hear world` | нет |
| `read file f into x` | читает в `x` весь файл `f` | нет |
| `write e to file f` | записывает `e` в файл `f` вместо того, что там было | нет |
| `append e to file f` | дописывает `e` в конец файла `f` | нет |
| `wait e seconds` | спит `e` секунд, пока остальные живут | пока спит |
| `endure` … `when it hurts as p` … `end` | переживает ошибки ([Перетерпеть](#перетерпеть)) | нет |
| `goodbye` | обрывает жизнь этой души | — |
| `goodbye with e` | обрывает жизнь этой души; программа кончится с кодом выхода `e` ([Как кончается программа](#как-кончается-программа)) | — |
| `mark m` | называет это мгновение жизни души именем `m` | нет |
| `return to m` | возвращается к мгновению `m` | нет |

Всем инструкциям, где упомянута `S`, нужна душа, которая существует и не
совпадает с самой этой душой. Всем, кроме `meet`, нужна душа, с которой эта
уже встречалась и от которой не ушла.

### Блоки

```
if e                while e             first time
    …                   …                   …
else                end                 end
    …
end
```

`if` и `while` исполняют своё тело, когда `e` истинно. `first time`
исполняет тело только при первом запуске программы ([Запуски](#запуски)).
`else` и `end` стоят каждый на своей строке одни. У `while` не бывает `else`.

`mark` и `return to` перемещаются только внутри того кода, где они написаны:
в теле души, рода или ритуала. Каждое мгновение можно отметить лишь однажды, а
`return to` требует мгновения, отмеченного где-нибудь в том же коде, выше или
ниже.

## Ритуалы

```
ritual greet who, how
    tell soul named who how
    give back length of how
end

soul alice
    meet bob
    perform greet with "bob", "hello" into n
end
```

Ритуал совершает та душа, которая к нему приступила: он встречается, говорит
и чувствует от её лица и пишет в её заметки. Переменных души он не видит. Его
память поначалу хранит только параметры, переданные по порядку после `with`;
значений должно быть ровно столько, сколько у ритуала параметров.

`give back e` завершает ритуал и кладёт `e` в переменную, указанную после
`into`, если она указана. Ритуал, дошедший до своего `end`, возвращает `0`.
Ритуалы могут совершать другие ритуалы и самих себя; но десять тысяч ритуалов,
вложенных друг в друга, — уже ошибка.

Пока ритуал длится, переменные совершившей его души хранятся нетронутыми и не
стареют: когда ритуал кончится, они будут так же свежи, как в тот миг, когда
он начался. Долгий ритуал не заставит душу забыть, чем она была занята.

## Роды и новые души

`kind` — это код душ, которых ещё нет. `bring K named e` призывает одну из них
к жизни: появляется новая душа по имени `e` и исполняет код `K`. Имя должно
быть непустой строкой, которую ещё не носит ни одна душа. Новая душа начинает
жить в следующем раунде, после всех, кто уже жил, и ничего не помнит.

`soul named e` позволяет любой инструкции или выражению дотянуться до души,
чьё имя становится известно лишь во время работы:

```
let i = 1
while i <= 3
    bring worker named "w" + i
    i = i + 1
end
meet soul named "w2"
tell soul named ("w" + 2) "start"
```

После `named` в `bring` может стоять целое выражение, а `soul named`
принимает только унарное, поэтому вычисленное имя заключают в скобки.

## Время: раунды и шаги

Души живут бок о бок. Мир движется раундами; в каждом раунде каждая живая
душа по очереди делает один шаг: пробует исполнить ту инструкцию, что стоит
перед ней. Если инструкцию пока исполнить нельзя (на встречу никто не пришёл,
слов никто не слушает), душа остаётся на месте и пробует снова в следующем
раунде.

Порядок душ в раунде — это порядок их объявлений, повёрнутый на число
запусков: в запуске номер `n` очередь начинается с души под номером
`n mod count`. Души, призванные к жизни позже, идут после всех остальных, в
том порядке, в каком родились.

Каждая душа ведёт счёт своим шагам; шаг души — это раунд, в котором она была
жива. Память и страсть выцветают с шагами самой души, а не с раундами мира.

Когда шаг завершает `meet`, `tell` или `hear`, он заодно переводит и другую
душу через её собственное `meet`, `tell` или `hear`: обе делают это вместе, в
шаге той из них, которая подошла второй.

## Встреча

`meet S` удаётся, когда `S` стоит на `meet`, обращённом к этой душе (по имени
или через `soul named`), или на `meet anyone`. `meet anyone as x` удаётся
только с душой, которая ищет эту по имени; две души, которые обе ждут
кого угодно, не встретятся никогда.

Две души не могут встретиться, если одна ушла от другой или одна закрылась от
другой после [раны](#раны).

После встречи обе души знакомы, обе помнят это мгновение, и страсть растёт с
обеих сторон: на три при любви с первого взгляда (на первой встрече, если обе
пришли к ней в одном и том же раунде), а иначе на единицу.

## Говорить и слышать

Слова переходят от одной души к другой, когда одна стоит на `tell S` или
`confide S`, а `S` стоит на `hear`, обращённом к этой душе, на `hear anyone`
или на `hear anyone … from`. Обе идут дальше; значение выражения, которое
говорящий вычисляет в этот самый миг, попадает в переменную слушающего.

Душа не слышит:

- ту, с которой ни разу не встречалась;
- ту, от которой закрылась после раны;
- ту, которую боится;
- никого из двоих, если одна ушла от другой.

`confide` позволено только с той душой, которой эта отдала сердце; попытка
довериться кому-то ещё — ошибка.

`hear anyone` берёт первого в очереди раунда говорящего, которого можно
услышать. Всё услышанное душа хранит; если одна из двух [уйдёт](#уход), это
обратится в шрамы.

### Ответы и страх

Каждая душа считает, сколько раз она заговаривала с другой, так и не
дождавшись ответа; назовём это давлением.

- Когда `B` слышит `A`, а сама в это время говорила с `A` без ответа, слова
  `A` становятся ответом: близость с обеих сторон растёт на единицу, и
  давление `B` на `A` пропадает.
- В любом случае давление `A` на `B` растёт на единицу.
- Когда давление `A` на `B` становится больше, чем близость `B` с `A` плюс
  два, `B` пугается: она перестаёт слышать `A` на «3 + давление» своих шагов,
  её страсть к `A` убывает на единицу, а давление `A` снова отсчитывается от
  нуля.

Так что между чужими пугает уже третье слово подряд без ответа (само оно
ещё услышано); между близкими для этого нужно больше.

## Отношения

У каждой души свой взгляд на каждую душу, с которой она встречалась:

| Составляющая | Вначале | Что её меняет |
|---|---|---|
| доверие (trust) | 0 | `warm to` +1, `cool to` −1 (не ниже 0), рана обнуляет |
| близость (intimacy) | 0 | +1 с обеих сторон за ответ, рана делит пополам |
| страсть (passion) | 0 | +3 с первого взгляда, +1 за каждую следующую встречу, пока она меньше 6, −1 за испуг, остывает в разлуке, любовь не даёт ей угаснуть |
| любовь (love) | 0 | строится, когда страсть хоть раз наполнилась, и прибавляет понемногу больше за каждые 150 шагов, проведённых рядом ([Любовь строится](#любовь-строится)) |
| верность (commitment) | 0 | `promise` +1, `leave` обнуляет |
| сердце отдано | нет | `give heart to` |
| закрыта | нет | рана, если сердце не было отдано; `forgive` открывает |
| шрамы | нет | раны и уход |

### Связи

`bond with S` называет отношения по тому, какие из трёх составляющих —
близость, страсть и верность — дошли до 3:

| Близость | Страсть | Верность | Связь |
|---|---|---|---|
| | | | пока ничего (`nothing yet`) |
| ✓ | | | симпатия (`liking`) |
| | ✓ | | влюблённость (`infatuation`) |
| | | ✓ | пустая любовь (`empty love`) |
| ✓ | ✓ | | романтическая любовь (`romantic love`) |
| ✓ | | ✓ | дружеская любовь (`companionate love`) |
| | ✓ | ✓ | безрассудная любовь (`fatuous love`) |
| ✓ | ✓ | ✓ | совершенная любовь (`consummate love`) |

Двое незнакомцев, встретившихся с первого взгляда, начинают со страстью 3 —
то есть с влюблённости.

### Любовь строится

Страсть и влюблённость — это искра, а не любовь. Пока страсть ни разу не
наполнилась (не дошла до 3), строить нечего. Но с этой минуты каждые 150
шагов, которые две души проводят рядом, давая знать о себе хотя бы раз в 50
шагов и не держа друг на друга обиды, прибавляют им любви, и каждый такой срок
прибавляет `1 + love / 5`: чем больше любви уже построено, тем быстрее она
растёт. Строит её и то, что им довелось пережить вместе: извинение, принятое
там, где есть любовь, прибавляет по единице обоим.

Чем крепче любовь, тем больше она проявляется:

- душу пугает лишь больше чем `intimacy + 2 + love` слов подряд без ответа;
- близость, которая без внимания убывает, не опускается ниже любви;
- с 3 рана уже не закрывает душу, словно та отдала сердце;
- с 6 рана не оставляет обиды, а слова между ними доходят сразу, как бы далеко
  они ни разошлись;
- страсть, которая без встреч остывает, не опускается ниже четверти любви,
  вплоть до полной: построенная любовь возвращает огонь, который зажгла искра.

`phase with S` проходит стадии Хелен Фишер и идёт дальше: влечение (`lust`),
пока есть одна только страсть, влюблённость (`attraction`), когда к ней
прибавилась близость, привязанность (`attachment`), когда любовь дошла до 3, и
любовь (`love`) — с 10. Долгая любовь так же проходит и через названия
Стернберга: с первого взгляда — влюблённость, потом романтическая любовь, с
верностью — совершенная; пока искра остывает, любовь может на время стать
дружеской, но построенная любовь растёт и возвращает страсть, и любовь снова
совершенная и с каждым годом крепче.

### Химия

Две души могут сделать всё как следует и всё-таки не полюбить друг друга. На
первой встрече пара получает химию, −1, 0 или 1, и это число прибавляется к
страсти обеих. Берётся оно из того, кто они такие, и из жизней, которые
программа уже прожила, так что ни объявить его, ни вычислить по коду нельзя.
В первой жизни программы химии нет: в первый раз ничто не стоит на пути.

Инфраструктуре нужна одна и та же жизнь при каждом запуске. У программы,
которая начинается строкой `deterministic`, запущена с `--deterministic` или
с выставленной переменной `TAINTED_DETERMINISTIC`, химии нет; таковы
Taintednetes и операторы.

### Страсть остывает

За каждые 50 собственных шагов, прошедших с последней встречи, страсть души к
другой остывает на единицу, пока не дойдёт до нуля. Новая встреча начинает
отсчёт заново. Страсть к душе, от которой ушли, больше не меняется.

### Расстояние и внимание

Две души отдаляются друг от друга, пока между ними ничего не происходит. За
каждые 50 собственных шагов без слова, письма или встречи расстояние души до
другой растёт на единицу; слова издалека проводят в пути столько же раундов,
прежде чем их можно услышать, а письмо приходит через столько же раундов после
того, как его отправили. Слова в пути — это идущее время, а не тупик. Каждая
встреча сокращает расстояние вдвое, так что близость возвращается понемногу.

Близость требует внимания: она убывает на единицу за каждые 100 шагов без
общения, а пока держится обида — за каждые 50. Доверие не убывает: на нём
язык и ведёт свои расчёты.

### Чувства

Чувства случаются в отношениях и меняют их.

| Чувство | Когда приходит | Что делает | Когда уходит |
|---|---|---|---|
| обида | вместе с раной | ответы больше не сближают двоих, а близость убывает вдвое быстрее | когда её признают или за рану попросят прощения |
| стыд | когда душа ранит того, кто отдал ей сердце | `ashamed before` | с извинением |
| ревность | когда тот, кому принадлежит сердце этой души, доверяет тайну другому | страсть растёт на единицу, близость убывает на единицу | остаётся |
| тоска | пока души далеко друг от друга, а страсть ещё не прошла | `longing for` | когда они снова рядом |
| благодарность | `thank S` | верность растёт, а `S` чувствует, что они стали ближе | остаётся |
| надежда | `hope for S` | страсть к `S` больше не остывает; в причитании сказано, что душа всё ещё надеется | остаётся |
| нежность | `tell S e tenderly` | слово не давит на `S` и делает её ближе | — |

### Извинения

Извинение называет рану, за которую просят прощения: `apologize to S for scar n`,
где `n` — номер шрама `"wounded by <this soul>"` среди шрамов, которые `S`
носит от этой души. Извинение без `for` не компилируется, а извинение за шрам,
который не был раной от этой души, — ошибка. Обида `S` уходит, стыд этой души
тоже, доверие `S` вырастает на единицу, и у `S` остаётся ещё один шрам:
`"<this soul> apologized for: wounded by <this soul>"`. Сама рана остаётся.

### Раны

`knowingly wound S` меняет то, какой `S` видит эту душу: доверие `S` падает до
нуля, близость делится пополам (с округлением вниз), у `S` остаётся шрам
`"wounded by <name>"`, а вместе с ним и обида на рану. Если `S` не отдавала
этой душе сердца, она к тому же
закрывается: не станет слышать эту душу и не встретится с ней, пока не
простит. Если отдавала, она остаётся открытой: отданное сердце и позволяет
отношениям пережить рану.

### Уход

`knowingly leave S` — это навсегда, для обеих. Верность этой души `S` обнуляется; всё,
что эта душа слышала от `S`, становится её шрамами, всё, что `S` слышала от
этой души, становится шрамами `S`, и у `S` остаётся ещё один:
`"<name> left"`. Ни одна больше не сможет встретиться с другой, сказать ей
что-нибудь или её услышать; если попробует та, что ушла, это ошибка, а
оставленная просто ждёт вечно.

## Память

Переменные выцветают. Переменная помнит шаг, на котором её трогали в последний
раз: присвоили через `let` или простое присваивание, наполнили через `hear`,
`meet anyone as` или `into` или прочли. Когда её читают, каждые полные 50
шагов души, прошедшие с тех пор, что-то у неё отнимают:

- у числа последняя значащая цифра превращается в ноль: через 50 шагов 1999
  становится 1990, через 100 — 1900;
- у строки пропадает последний символ: через 50 шагов `"hello"` становится
  `"hell"`;
- у дроби сперва пропадает последняя цифра после точки, а когда их не
  останется — цифры целой части;
- список теряет последний элемент, словарь — последний ключ.

С этих пор душа помнит именно выцветшее значение, а само чтение снова трогает
переменную. `recall a b` читает переменные лишь затем, чтобы освежить их.
Долгий цикл, который на каждом обороте трогает свой счётчик, ничем не
рискует; а переменная, которой цикл не пользуется, пока он крутится,
выцветает.

Параметры ритуала свежи в тот миг, когда ритуал начинается, а переменные
совершающей его души хранятся, пока он длится.

### Воспоминание переписывает

Прочесть воспоминание, не переписав его, нельзя. Когда душа читает выцветшую
переменную, утраченное восполняется концом того, что она услышала последним,
если услышанное было той же природы: потерянные цифры числа — последними
цифрами услышанного числа, потерянные буквы строки — концом услышанной строки.
Душа, которая помнила 1999 год, а последним услышала 47, вспомнит 1997; та,
что не слышала ничего или слышала слова, вспомнит 1990.

### Заметки

`note k = e` записывает `e` под ключом `k`, превращённым в строку: `note 1` и
`note "1"` — одна и та же заметка. Заметки не выцветают никогда, они
принадлежат душе, и ритуалы, которые она совершает, пользуются ими вместе с
ней. Прочесть заметку, которую никто не писал, — ошибка. Заметками программа
на Tainted и ведёт таблицы: `note ("likes " + name)`.

## Запуски

Tainted помнит, сколько раз запускалась каждая программа. Перед запуском
программа ищет SHA-256 исходного текста, из которого её скомпилировали, в
`~/.tainted/history.json` (или в файле, который указан в `TAINTED_HISTORY`),
берёт найденное число как `runs` и записывает обратно на единицу больше. Стоит изменить в программе хотя
бы один символ, и она станет новой программой, которая не запускалась ни разу.

При первом запуске `runs` равно `0`, блоки `first time` исполняются только
тогда, а порядок душ в раунде с каждым запуском поворачивается на одну, так
что программа с несколькими душами никогда не проживёт одну и ту же жизнь
дважды подряд.

## Мир

`hear world into x` читает в `x` одну строку, без её перевода строки, из того,
что говорит мир: из стандартного ввода и из каждой команды, которую слушает
программа. Когда все они умолкнут, приходит число `0`, так что цикл
`while line != 0` читает всё до конца. Мир — не душа: с ним нельзя
встретиться, ему нельзя ничего сказать и его нельзя ранить.

`listen to world c` запускает команду `c` через `/bin/sh`; каждая строка,
которую она печатает, — ещё одно слово мира. Душа, ждущая мира, не
застревает: когда больше никто не может сдвинуться с места, весь мир не
кончается, а ждёт следующей строки. Так же он ждёт и душу, которая спит,
`wait n seconds`.

`ask world c into x` запускает `c` через `/bin/sh` и ждёт, пока она
кончится; в `x` попадает всё, что она напечатала, без последнего перевода
строки. С `telling t` команда читает `t` со своего входа. Команда, которая
кончилась с кодом выхода, отличным от 0, — ошибка, и душа может её
[перетерпеть](#перетерпеть); в ошибке сказано, что команда напечатала в
стандартный поток ошибок.

`read file`, `write … to file` и `append … to file` читают и пишут файлы
целиком; пути отсчитываются от того места, где запущена программа.

### Тишина

`wait for silence` ждёт, пока ни одна душа не сможет ничего сделать: все
остальные кого-то ждут, и ни с кем нельзя ни встретиться, ни заговорить, ни
услышать. Тогда все души, ждавшие тишины, идут дальше вместе, в одном и том же
раунде. Если душа ждёт тишины, а мир ещё не всё сказал, она сперва дождётся
мира.

Так программа на Tainted узнаёт, что вычисление, разбросанное по множеству
душ, улеглось: планировщик в `taintednetes.tainted` ждёт тишины и только
потом спрашивает каждый под, где тот живёт.

## Прежде чем души встретятся

Компилятор смотрит, что души сделают друг с другом, ещё до того, как они
встретятся, и три вещи не допускает.

### Чего не вернуть

Признание, рану и уход не отменишь, поэтому их совершают только сознательно:
`knowingly confide S e`, `knowingly wound S`, `knowingly leave S`. Без этого
слова программа не компилируется. Простить после них можно; шрам остаётся.

### Диалоги

Когда две души называют в своём коде друг друга, компилятор по порядку
читает, что каждая из них делает с другой: встречи, сказанные и услышанные
слова, общие дела. Одно должно отвечать другому: встреча — встрече, сказанные
слова — услышанным, `together` — `together`. Две души, которые обе ждут, когда
заговорит другая, или обе заговаривают первыми, или одна из которых говорит
то, чего другая никогда не слушает, не уживутся, и программа не компилируется:

```
tainted: line 3: a and b cannot get along: here a tells b, but at line 7 b tells a
```

Сравнивается только то, в чём нет сомнений. Душа, чьих собеседников по коду не
угадать (та, что совершает ритуалы, встречает или слушает незнакомцев,
отмечает мгновения), в сравнении не участвует, как и всё, что стоит внутри
`if`, `while` или другого блока. После раны, ухода или `goodbye` дальше идёт
история самих душ, и компилятор сравнивать перестаёт.

### Одно сердце

Сердце отдают одной душе за раз. Душа, чей код отдаёт сердце двум разным душам
по имени и ни разу не забирает его обратно через `take back heart from`, не
компилируется. Если же это всё-таки случается во время работы, через
вычисленное имя, сердце переходит к новой избраннице: та, у которой оно было,
теряет его и хранит шрам `"<giver> gave their heart to <new>"`, а отдавшая —
шрам `"gave my heart to <new>"`. Знают обе.

## Как любят

```
soul ana is anxious and agape
kind pod is avoidant
```

Душа или род может сказать, как любит; души одного рода любят так же, как их
род. Стили привязанности — это способы ждать, стили Джона Алана Ли — способы
чувствовать.

| Стиль | Что меняется |
|---|---|
| `secure` (надёжный) | ничего: правила такие, как написаны |
| `anxious` (тревожный) | каждый четвёртый шаг душа тратит на то, чтобы спросить, здесь ли ещё другая, и эти вопросы на другую давят |
| `avoidant` (избегающий) | на встречу она приходит и слова слышит, только выждав два раунда, даже если была готова раньше |
| `eros` (эрос) | страсть с первого взгляда — 5, а не 3, и остывает она вдвое быстрее |
| `ludus` (людус) | обещания не прибавляют ей верности, а уход не оставляет ей шрамов |
| `storge` (сторге) | доверие растёт на единицу за каждое второе `warm to`; `cool to` ничего не отнимает, а рана лишь делит доверие пополам |
| `pragma` (прагма) | сердце она отдаёт только там, где доверяет хотя бы на 3; попытка отдать его иначе — ошибка |
| `mania` (мания) | спрашивает, как тревожная душа, и ревнует к каждому слову, которое та, кому принадлежит её сердце, говорит другому, — причём вдвое сильнее |
| `agape` (агапе) | рана её не закрывает, и обиды она не держит |

Неизвестный стиль не компилируется.

## Согласие

```
together with ben
    …               done together
apart
    …               if it stopped halfway
end
```

Что две души делают вместе, они делают только с согласия обеих. Душа даёт
согласие через `consent to S` и забирает его через `withdraw consent from S`.
`together with S` ждёт, пока `S` не встанет на `together with`, обращённое к
этой душе, и пока обе не согласятся; тогда обе входят в блок. Что бы ни
происходило внутри, каждая душа идёт своими шагами; на `end` блока каждая ждёт
другую, и дальше они идут, только когда пришли обе, так что общее дело делают
либо обе, либо ни одна.

Согласие можно отозвать в любой миг, любой из двух, даже посередине. Если его
отзовут, или одна из душ уйдёт, или её не станет, обе останавливаются там, где
были, ритуалы, в которых они находились, обрываются, и обе переходят к
`apart`. Блок без `apart` просто кончается.

## Границы

Душа читает заметку другой души через `note k of S`, если `S` её впускает. Для
открытой заметки нужно расчётное доверие `S` (`S` хотя бы раз потеплела к этой
душе); заметка, которую `S` держит за своей границей через `guard k`,
открывается только той душе, которой `S` отдала сердце, и каждое пересечение
границы видят обе: `crossings with S` растёт с обеих сторон. Без этого чтение —
ошибка, и в ней названа граница.

## Письма и горе

`send S e` пишет `S` письмо и сразу идёт дальше, не дожидаясь `S`. Письмо
приходит через столько раундов, насколько души далеки друг от друга, и ждёт,
пока `S` не прочтёт его через `receive from` или `receive anyone`. Письма
хранятся и тогда, когда той, что их написала, уже нет: остановить их нельзя,
можно только прочесть. Всё, чего душа не прочла из писем ушедших душ, она,
кончаясь, хранит как шрамы.

## Перетерпеть

```
endure
    …
when it hurts as pain
    …
end
```

Ошибка обрывает программу, если только душа, которая её совершила, не стоит
внутри `endure`. Тогда душа идёт дальше с того места, что следует за
`when it hurts as pain`, а в `pain` лежит причина — строка вроде
`"there is no item 5 in a list of 1"`. Что бы ни пошло не так внутри, как бы
глубоко в ритуалах это ни случилось, душа возвращается в тот ритуал, где она
терпела, а ритуалы, в которых она побывала по дороге, обрываются, и их память
пропадает вместе с ними. Ошибку, совершённую, пока душа слушает другую (в
значении, которое вычисляет говорящая), терпеть приходится слушающей.

## Изучить файл

```
learn "kube.tainted"
```

В начале программы, вне всякой души, `learn` приносит в неё роды и ритуалы
другого файла, будто они были написаны тут же. Файл ищут рядом с программой
(`TAINTED_DIR`, его выставляет `bin/tc`), потом в библиотеке (`TAINTED_LIB`,
по умолчанию `lib/`). Файл, изученный дважды, изучается один раз. Ошибка в
изученном файле называет его: `line 7 of kube.tainted, s: …`. Изученные файлы
входят в исходный текст программы, а значит, и в историю её запусков.

## Как кончается программа

| Код выхода | Когда |
|---|---|
| 0 | каждая душа дошла до своего конца или сказала `goodbye` |
| `e` | каждая душа дошла до своего конца, и последняя из сказавших `goodbye with e` назвала это число, от 0 до 255 |
| 1 | ошибка: промах в программе или что-то, чего душа сделать не может |
| 2 | все, кто остался, кого-то ждут, и никто не может сдвинуться с места |
| 4 | у мира кончилось терпение ([Константы](#константы)) |
| 64 | программу вызвали неправильно |

Когда ждут все, Tainted причитает в стандартный поток ошибок:

```
the end.
bob is still waiting for alice, who left
carol is still waiting for anyone at all
```

Ошибка называет строку и душу:
`tainted: line 7, alice: alice can confide only in someone they gave their heart to`.

## Командная строка

```
make                                build the compiler, build/tc-core, from the seed
bin/tc program.tainted              compile a program to ./program
bin/tc program.tainted -o path      compile it to path
bin/tc program.tainted -c           print the C the compiler makes of it
./program                           run it; the world is its standard input
./program --feelings                run it, then print every relationship
./program --patience=N              give up after N rounds
./program --deterministic           no chemistry, the same life every run
./program --lineage                 say which compilers made it, and stop
bin/tc compiler.tainted --give-heart
                                    rebuild the heart of the compiler
bin/tc compiler.tainted --give-heart --forgive
                                    rebuild it after a wound
make ddc                            the seed and the living compiler remember each other
```

По порядку: собрать компилятор `build/tc-core` из затравки; скомпилировать
программу в `./program`; скомпилировать её в указанный путь; напечатать C,
который компилятор из неё делает; запустить её, и миром для неё станет
стандартный ввод; запустить, а потом напечатать все отношения; сдаться после
N раундов; запустить без химии, чтобы каждый раз прожить одну и ту же жизнь;
сказать, какие компиляторы её сделали, и на этом остановиться; пересобрать
сердце компилятора; пересобрать его после раны; дать затравке и живому
компилятору вспомнить друг друга.

`--feelings` печатает в стандартный поток ошибок по строке на каждую пару из
души и той, с кем она встречалась:

```
alice -> bob: romantic love; trust 3, intimacy 4, passion 3, commitment 0, scars 0, heart given
```

Программа, которая не компилируется, завершает компилятор с кодом выхода 1 и
объяснением: `tainted: line 4: expected 'of'`.

## Компилятор

`compiler.tainted` — это компилятор. Он и сам программа на Tainted: слышит
программу из мира, строку за строкой, и говорит программу на C, которая,
собранная вместе с `runtime/tainted.c`, проживёт ту же жизнь. `bin/tc`
запускает компилятор и компилятор C один за другим.

- Каждая душа, каждый род и каждый ритуал становятся отдельной единицей:
  таблицей своих инструкций и функцией шага. В таблицу заглядывают другие
  души (ждёт ли эта встречи с ними, хочет ли что-то им сказать, слушает ли
  их); функция шага исполняет ту инструкцию, что стоит перед душой.
- Каждое выражение становится собственной функцией на C и вычисляется слева
  направо; `and` и `or` смотрят на правую часть, только когда без неё не
  обойтись.
- Всё, что происходит между душами, берёт на себя среда исполнения: раунды,
  встречи, слова, страх, отношения, память и её выцветание, ритуалы, мир и
  историю запусков. Правила у неё те самые, что описаны в этом справочнике.
- Исходный текст программы хранится внутри программы, в которую она
  компилируется, поэтому программа сама ведёт счёт своим запускам.

Компилятор компилирует сам себя, и неподвижной точки у него нет. Каждое
поколение помнит поколения, бывшие до него, и вписывает в то, что делает, их
родословную и собственную строку, поэтому никакие два поколения не бывают
одним и тем же файлом. Вместо того чтобы быть одинаковыми, они узнают друг
друга: получив одни и те же программы, о каждой из них говорят одно и то же,
если не считать памяти. `tools/recognize.tainted` проверяет это на каждой
записанной программе и на самом компиляторе.

```
make                 the seed boot/tc.c gives its heart and compiles the compiler afresh: build/tc-core
make bootstrap       build/tc-core compiles the compiler into generation 2, 2 into 3, and 2 and 3 must recognize each other
make seed            the newest generation becomes the seed
```

По порядку: затравка `boot/tc.c` вручает своё сердце и заново компилирует
компилятор в `build/tc-core`; `build/tc-core` компилирует компилятор во второе
поколение, второе — в третье, и второе с третьим должны узнать друг друга;
новейшее поколение становится затравкой.

`compiler.tainted` начинается строкой `core`: это сердце компилятора.
Собственное сердце компилятор пересобирает, только когда вручает его самому
себе, командой `bin/tc compiler.tainted --give-heart` (или через
`TAINTED_GIVE_HEART`); без этого он отказывается. Новому правилу языка
компилятор сперва учат теми словами, которые понимает уже предыдущее
поколение.

### Шрамы и прощение

Когда компилятору не удаётся пересобрать собственное сердце, неудача
становится раной, которую он помнит вне всякой программы, в `TAINTED_MEMORY`
(по умолчанию `~/.tainted/compiler.json`). Пока его не простят, своего сердца
он больше не пересоберёт: `bin/tc compiler.tainted --give-heart --forgive`.
Простить не значит забыть: рана становится шрамом нового поколения и остаётся
в его родословной:

```
scar of generation 4: tainted: line 20: expected a name, got '(', forgiven
```

### Выцветание

Компилятор, которого не пересобирают, выцветает. Тот, что сделан больше 90
дней назад, не компилирует ничего, кроме собственного сердца, и просит, чтобы
его пересобрали; `make` всегда пересобирает компилятор из затравки, поэтому
живое поколение никогда не бывает старше последнего `make -B build/tc-core`.
`TAINTED_CLOCK` задаёт время для тестов.

### Помнить друг друга

Кену Томпсону Дэвид А. Уилер ответил так: собрать исходный текст компилятора
двумя разными компиляторами, дать каждому результату собрать этот текст ещё
раз и сравнить. `make ddc` делает это с затравкой и живым поколением:
`tools/ddc.tainted` поручает каждому из них собрать компилятор, а двое детей
собирают его ещё раз; если дети говорят одно и то же, не считая памяти, значит,
оба компилятора помнят друг друга одинаково и ни один не несёт в себе ничего,
чего нет в исходном тексте.

### Компиляция как свидание

Компилятор переводит только ту программу, которая на это согласилась:
`written by "имя"` в начале программы — её согласие, а программу без него
компилятор отвергает. Файл, из которого программа учится, тоже может сказать,
кто его написал; это лишь имя автора файла, а не согласие программы.

Своих авторов компилятор помнит в собственной памяти, рядом со своими ранами:
каждая скомпилированная программа автора прибавляет доверия к нему. Программа
того, кому компилятор доверяет меньше чем на 3, — программа незнакомца, и
читают её внимательнее: каждая переменная, которую она читает, должна где-то
запоминаться в той же душе, роде или ритуале, иначе программа не
компилируется; программа автора, которому компилятор доверяет, наткнётся на
такую ошибку лишь при запуске. Автор вписывается в родословную программы:

```
a program by ana, from 51fa19e57b34, made by generation 9
```

### Родословная

Каждая программа несёт родословную компиляторов, которые её сделали, по
строке на каждый, от старшего к младшему, и произносит её, если запустить её
с `--lineage`:

```
generation 4 of the compiler, from 409f651a051f, made by generation 3, at 1795016256
generation 5 of the compiler, from 409f651a051f, made by generation 4, at 1795016257
a program, from 51fa19e57b34, made by generation 5
```

`from` — начало SHA-256 исходного текста, `at` — время, когда поколение было
сделано. Кен Томпсон показал, что компилятор может переносить из поколения в
поколение то, чего нет ни в каком исходном тексте; в Tainted всё, что несёт
каждое поколение, лежит на виду. Свою родословную программа читает через
`lineage`, свой исходный текст — через `source`, а `hash of x` — это SHA-256
от `x` как текста.

Компилятор забывает, как любая душа. Всё, что должно пережить несколько
шагов, он записывает в заметки, а там, где цикл тянется долго, вспоминает то,
что понадобится ему потом. Компилятор, который не вспоминает имя функции,
которую пишет, теряет из него буквы и выдаёт C, который не собирается; тесты
это проверяют.

## Константы

| Название | Значение | Смысл |
|---|---|---|
| выцветание | 50 шагов | переменная теряет цифру или символ |
| остывание | 50 шагов | страсть в разлуке убывает на единицу |
| составляющая связи | 3 | близость, страсть или верность засчитывается в связь |
| первый взгляд | +3 | страсть от первой встречи в одном раунде |
| страх | давление > близость + 2 | слушающая душа пугается |
| терпение | 10,000,000 раундов | программу, которая работает дольше, останавливают, код выхода 4 |
| ритуалы | 10,000 в глубину | ритуалы внутри ритуалов |

## Чего в Tainted нет

Одного здесь нет нарочно, другое пока не написано; программе приходится
обходиться без них.

- Вызов ритуала — инструкция, а не выражение.
- Строка не может содержать символ с кодом 0.
